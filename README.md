# AniLiberty для Jellyfin

Плагин для [Jellyfin](https://jellyfin.org) 12, который превращает локальный архив торрентов
[AniLiberty](https://aniliberty.top) (в том числе старые раздачи AniLibria.TV) в аккуратную медиатеку:

- **Метаданные с AniLiberty** — русские названия, описания, жанры, возрастной рейтинг, постеры,
  названия серий, команда озвучки. Если релиз не найден на AniLiberty, данные берутся
  с [Shikimori](https://shikimori.rip).
- **Точное сопоставление по имени торрента.** Имя папки/файла, которое создаёт торрент AniLiberty,
  совпадает с `dn` в magnet-ссылке API — так находится ≈92% релизов без угадывания.
- **Синхронизация с аккаунтом AniLiberty — у каждого пользователя Jellyfin свой аккаунт:**
  прогресс и «просмотрено» в обе стороны, избранное, коллекции сайта
  («Смотрю», «Запланировано», …) как личные плейлисты. Вход по одноразовому коду, пароль в Jellyfin не вводится.
- **«Пропустить опенинг/эндинг»** во всех клиентах — по разметке опенингов и эндингов AniLiberty
  (есть примерно у 85% серий).
- **Франшизы** — коллекции Jellyfin в порядке просмотра с сайта
  (например, «Моя геройская академия»: 1 → 2 → 3 → «Два героя» → 4 → …), сериалы и фильмы вместе.
- **Один сериал на релиз с выбором версии.** Скрипт [`scripts/aniliberty-tree.py`](scripts/aniliberty-tree.py)
  собирает дерево симлинков, в котором AVC, HEVC и 720p-раздачи одного релиза становятся версиями
  одной серии, а одиночные файлы из корня архива — отдельной медиатекой фильмов.

> Неофициальный проект, не связан с командой AniLiberty. Плагин только читает публичное API сайта
> и API аккаунта пользователя, который сам его привязал.

## Требования

| | |
|---|---|
| Jellyfin | **12.1** и новее (плагин собран под .NET 10, на 10.x не загрузится) |
| Архив | торренты AniLiberty **с оригинальными именами папок и файлов** |
| Для дерева симлинков | Linux-хост или контейнер с Jellyfin, Python 3, systemd (или любой планировщик) |
| Сеть | доступ к `aniliberty.top` и `shikimori.rip` с сервера Jellyfin ([см. «Россия и Cloudflare»](#россия-и-cloudflare)) |

Переименованные или скачанные не с AniLiberty релизы тоже обработаются, но только поиском по названию — это заметно менее точно.

## Установка

1. **Панель управления → Плагины → Репозитории → «+»**, адрес:
   ```
   https://raw.githubusercontent.com/qDgey/jellyfin-plugin-aniliberty/main/manifest.json
   ```
2. **Каталог → AniLiberty Metadata → Установить**, перезапустить Jellyfin.

Вручную: скачать zip из [Releases](https://github.com/qDgey/jellyfin-plugin-aniliberty/releases),
распаковать `Jellyfin.Plugin.AniLiberty.dll` в `<каталог данных Jellyfin>/plugins/AniLiberty_<версия>/`
(для deb/Ubuntu — `/var/lib/jellyfin/plugins/`) и перезапустить Jellyfin.

## Медиатеки

### Нужен ли скрипт деревьев

Сам плагин (метаданные, синхронизация аккаунтов, франшизы, пропуск опенингов) работает в любом случае —
скрипт только раскладывает файлы так, как их лучше понимает Jellyfin. Он ничего не меняет в архиве.

| Как устроен архив | Скрипт | Почему |
|---|---|---|
| Одна версия каждого релиза (например, качаете только HEVC), каждый сериал — отдельная папка раздачи прямо в корне, фильмов нет или они лежат в отдельной папке | **не нужен** | Медиатека «Телешоу» прямо на папку с сериалами, «Фильмы» — на папку с фильмами. Плагин найдёт релизы по именам папок и сам исправит номера серий `[01]` |
| То же, но фильмы/OVA-файлы лежат вперемешку с папками сериалов | желательно | Без скрипта такие файлы в «Телешоу» скрываются плагином и в медиатеку не попадают; со скриптом они уходят в «Фильмы» |
| Архив разложен по подпапкам: годы, «Онгоинги», «Завершённые», жанры… | **нужен** | Jellyfin считает сериалом каждую папку первого уровня — «2016» стал бы одним огромным сериалом |
| Есть несколько раздач одного релиза: AVC и HEVC, 1080p и 720p, старая и новая | **нужен** | Иначе каждая раздача — отдельная карточка сериала с дублями серий; со скриптом — одна карточка, у серий выбор версии |
| Архив на нескольких дисках/в нескольких папках, релизы в них пересекаются | **нужен** | Скрипт собирает все корни в одно дерево и объединяет одинаковые релизы |
| Раздачи с подпапками сезонов (`Season 1/`, `Сезон 2/`) | желательно | Jellyfin их поймёт и сам, но скрипт вдобавок объединит их с другими раздачами того же релиза |

Если сомневаетесь — запустите установщик: он сначала показывает пробный прогон (сколько найдено сериалов,
серий, фильмов и примеры будущих ссылок) и ничего не делает без подтверждения.

### Вариант А — с деревом симлинков (рекомендуется)

Одна карточка на релиз, у каждой серии выбор версии («AVC WEBRip» / «HEVC WEBRip», «720p» / «1080p»),
фильмы отдельно. По умолчанию играется AVC (работает на любых телевизорах); `--prefer hevc` /
`ANILIBERTY_PREFER=hevc` делает версией по умолчанию HEVC.

```
/media/aniliberty/86 - Eighty Six - AniLibria.TV [WEBRip 1080p]/86_Eighty_Six_[01]_[AniLibria_TV]_[WEBRip_1080p].mkv
/media/aniliberty/86 - Eighty Six - AniLibria.TV [WEBRip 1080p HEVC]/86_Eighty_Six_[01]_..._HEVC].mkv
/media/aniliberty/Fairy_Tail_Dragon_Cry_[AniLibria_TV]_[BDRip_1080p].mkv
        ↓  aniliberty-tree.py
/srv/aniliberty-series/86 - Eighty Six/Season 01/86 - Eighty Six S01E01 - 1080p AVC WEBRip.mkv
/srv/aniliberty-series/86 - Eighty Six/Season 01/86 - Eighty Six S01E01 - 1080p HEVC WEBRip.mkv
/srv/aniliberty-movies/Fairy Tail Dragon Cry/Fairy Tail Dragon Cry - 1080p AVC BDRip.mkv
```

Оригинальные файлы не трогаются (раздача продолжает работать), в дереве только симлинки.
Скрипт ставится туда же, где работает Jellyfin (хост, LXC или VM; для Docker — см. ниже).

#### Какая структура архива поддерживается

Любая — скрипт сам находит раздачи, обходя папки вглубь:

```
/data/anime/                              ← корень (их может быть несколько, например на разных дисках)
├── 2016/                                 ← группирующая папка (годы, категории…) — в неё заходим
│   └── Boku no Hero Academia - AniLibria.TV [WEBRip 1080p]/   ← раздача: папка с видео
│       ├── Boku_no_Hero_Academia_[01]_….mkv
│       └── Extras/                       ← пропускается
├── Фильмы/
│   ├── Kimi_no_Na_wa_[AniLibria]_[BDRip_1080p].mkv            ← одиночный файл — фильм
│   └── Tenki no Ko - AniLibria [BDRip 1080p]/Tenki_no_Ko_….mkv ← папка с одним файлом без номера — фильм
└── Gintama - AniLibria.TV [WEBRip 1080p]/
    ├── Season 1/Gintama_[01]_….mkv       ← подпапки сезонов (Season N, Сезон N, S0N)
    └── Season 2/Gintama_[03]_….mkv
/mnt/disk2/anime/Онгоинги/Boku no Hero Academia - AniLibria.TV [WEBRip 1080p HEVC]/…
                                          ← вторая раздача того же релиза на другом диске → вторая версия серий
```

- **раздача** — папка, в которой прямо лежат видео (и, возможно, подпапки сезонов);
  несколько серий → сериал, один файл без номера серии (`[01]`) → фильм;
- **группирующая папка** — любая другая (корень, годы, «Фильмы», «Онгоинги»…); видео прямо в ней — фильмы;
- раздачи одного релиза из разных мест (AVC/HEVC, 1080p/720p, разные диски) объединяются по названию;
- пропускаются скрытые папки, `Extras`/`Bonus`/`Samples`/`NCOP`/… и то, что подходит под `ANILIBERTY_EXCLUDE`;
- глубина поиска — `ANILIBERTY_MAX_DEPTH` (по умолчанию 4 уровня группирующих папок).

#### Установка одной командой

```bash
curl -fsSL https://raw.githubusercontent.com/qDgey/jellyfin-plugin-aniliberty/main/scripts/install.sh | sudo bash -s -- --source /data/anime
```

Несколько корней — несколько `--source`. Без параметров установщик спросит пути сам. Что он делает:

1. ставит `/usr/local/bin/aniliberty-tree.py` и пишет конфиг `/etc/aniliberty-tree.conf`;
2. создаёт папки деревьев (по умолчанию `/srv/aniliberty-series`, `/srv/aniliberty-movies`) с владельцем `jellyfin`;
3. показывает пробный прогон (сколько найдено раздач, серий, фильмов, примеры ссылок) и спрашивает, строить ли;
4. ставит systemd-таймер на пересборку раз в час (без systemd — подскажет строку для cron).

Параметры: `--series DIR`, `--movies DIR`, `--user USER` (от чьего имени работает Jellyfin),
`--depth N`, `--exclude REGEX`, `--prefer avc|hevc`, `--no-run`, `--no-timer`, `--yes` (без вопросов), `--uninstall`.
Повторный запуск берёт значения из существующего конфига — так же обновляется скрипт.

Проверить, что получится, ничего не меняя:

```bash
sudo -u jellyfin bash -c 'set -a; . /etc/aniliberty-tree.conf; set +a; python3 /usr/local/bin/aniliberty-tree.py --dry-run --list 20'
```

#### Установка вручную

```bash
sudo install -m 755 scripts/aniliberty-tree.py /usr/local/bin/
sudo install -m 644 scripts/aniliberty-tree.conf /etc/            # поправить пути в нём
sudo install -m 644 scripts/aniliberty-tree.service scripts/aniliberty-tree.timer /etc/systemd/system/
sudo mkdir -p /srv/aniliberty-series /srv/aniliberty-movies
sudo chown jellyfin:jellyfin /srv/aniliberty-series /srv/aniliberty-movies
sudo systemctl daemon-reload
sudo systemctl start aniliberty-tree.service                      # первая сборка
sudo systemctl enable --now aniliberty-tree.timer                 # дальше — раз в час
```

Если Jellyfin работает не от `jellyfin` или архив на NFS/SMB — добавьте в
`systemctl edit aniliberty-tree.service`:

```ini
[Unit]
RequiresMountsFor=/data/anime
[Service]
User=<пользователь Jellyfin>
```

Или без systemd, просто по cron: `17 * * * * set -a; . /etc/aniliberty-tree.conf; set +a; python3 /usr/local/bin/aniliberty-tree.py`.

Скрипт идемпотентный: добавляет новые релизы и убирает ссылки на исчезнувшие файлы.
Если какой-то корень не смонтирован (пустой каталог), он ничего не меняет.

**Jellyfin в Docker:** скрипт запускается на хосте (от пользователя с тем же UID, что у Jellyfin
в контейнере), а в контейнер пробрасываются архив и оба дерева **по тем же путям**, что на хосте —
симлинки указывают на абсолютные пути источника:

```yaml
volumes:
  - /data/anime:/data/anime:ro
  - /srv/aniliberty-series:/srv/aniliberty-series:ro
  - /srv/aniliberty-movies:/srv/aniliberty-movies:ro
```

Медиатеки:

| Медиатека | Тип | Папка |
|---|---|---|
| Аниме | Телешоу | `/srv/aniliberty-series` |
| Аниме — фильмы | Фильмы | `/srv/aniliberty-movies` |

### Вариант Б — прямо на архив

Подходит для простого архива из первой строки таблицы выше: медиатека «Телешоу» на папку с раздачами сериалов,
«Фильмы» — на папку с фильмами (каждый фильм — файл или папка с одним файлом). Если в папке сериалов
попадаются одиночные файлы, плагин скрывает их из «Телешоу», чтобы они не превращались в «серии без сериала».

### Настройки медиатек

- язык метаданных — **Русский**, страна — **Россия**;
- в загрузчиках метаданных и изображений для сериалов, сезонов, эпизодов и фильмов — **AniLiberty** первым
  (TheMovieDb/OMDb можно выключить — они плохо находят аниме по этим названиям);
- **мониторинг в реальном времени — выкл.** (на сетевых ФС не работает);
- **trickplay и изображения глав — выкл.**, иначе первое сканирование прочитает весь архив целиком;
- NFO и «сохранять изображения рядом с медиа» — выкл., если архив только для чтения;
- **поставщики медиасегментов — AniLiberty не выключен** (включён по умолчанию; нужен для кнопки «Пропустить опенинг»).

## Аккаунт AniLiberty (у каждого пользователя свой)

Страница привязки: **`http://<ваш-jellyfin>/AniLiberty/Link`** — открыть в браузере, где выполнен вход
в Jellyfin (с телефона тоже можно). Ссылка есть и в настройках плагина — дайте её пользователям.

1. «Получить код» → на странице появится код.
2. Открыть [aniliberty.top/app/auth/otp/linkDevice](https://aniliberty.top/app/auth/otp/linkDevice)
   (войти там, если нужно) и ввести код.
3. Страница сама переключится на «Привязан: <ник>».

Если в настройках плагина включён пункт меню (по умолчанию да), у пользователей веб-клиента и мобильного
приложения в боковом меню есть **«AniLiberty»** — это и есть страница привязки.

Дальше синхронизация идёт на сервере и работает **во всех клиентах Jellyfin** — ТВ, телефоны, браузер:

| | Jellyfin → AniLiberty | AniLiberty → Jellyfin |
|---|---|---|
| Прогресс серии | во время просмотра (раз в минуту) и при остановке | задача «Синхронизация аккаунтов AniLiberty», каждые 15 мин |
| «Просмотрено» | досмотр ≥90% или ручная отметка; снятие отметки удаляет таймкод | ставится на все версии серии |
| Избранное | сердечко на сериале/фильме (≈10 с) | ♥ на соответствующих сериалах |
| Коллекции | правка плейлистов «AniLiberty: …»; просмотр сам переносит релиз в «Смотрю», последняя серия завершённого релиза — в «Просмотрено» | 5 личных плейлистов: Смотрю / Запланировано / Просмотрено / Отложено / Брошено |

- При первой привязке всё объединяется: история с сайта подтягивается, отметки из Jellyfin уходят на сайт, ничего не удаляется.
- Если Jellyfin пересоздал элементы медиатеки (сменились пути, пересобрано дерево) и отметки «пропали» массово,
  плагин считает это пересборкой, а не действием пользователя, и снова объединяет данные, ничего не удаляя на сайте.
- Таймкоды AniLiberty не содержат даты изменения, поэтому «новее побеждает» определяется сравнением
  с состоянием на прошлой синхронизации.
- Синхронизируются только релизы, найденные на AniLiberty (для взятых с Shikimori нет ID серий на сайте).
- Токены хранятся в `<данные плагина>/accounts.json` (права 0600) и не попадают в настройки плагина,
  но администратор сервера технически может их прочитать.

## Пропуск опенингов

AniLiberty размечает опенинги и эндинги серий. Плагин отдаёт их Jellyfin как сегменты «Интро» / «Аутро» —
клиенты показывают кнопку «Пропустить» (или пропускают сами, если так настроено в клиенте).

1. В настройках медиатеки сериалов среди поставщиков медиасегментов должен быть включён **AniLiberty** (по умолчанию так и есть).
2. Запустить задачу **«Сканирование медиасегментов»** (Панель → Планировщик) после того, как медиатека просканирована.

Разметка сделана на версии с сайта; торренты той же раздачи совпадают с ней, у BD-версий возможен сдвиг на пару секунд.

## Франшизы

Задача **«Франшизы AniLiberty»** забирает с сайта все франшизы и создаёт коллекции Jellyfin
(с постером франшизы) для тех, у которых в медиатеке есть хотя бы 2 релиза. Элементы идут в порядке
просмотра с сайта, а не по дате. Запускается после каждого сканирования медиатеки и ежедневно в 5:00.
Коллекции общие для всех пользователей.

## Россия и Cloudflare

AniLiberty работает за Cloudflare. У многих российских провайдеров соединения с Cloudflare «замирают»
после первых ~16–27 КБ: API-ответы плагин запрашивает сжатыми (так они проходят), но постеры
зависают и скачиваются с повторами, что сильно замедляет первое сканирование. Если вы в России,
пустите интернет-трафик сервера Jellyfin через VPN/прокси (на уровне хоста или маршрутизатора).

## Первое сканирование

Большой архив (тысячи релизов, десятки тысяч серий) сканируется часами: Jellyfin по очереди
анализирует каждый файл. Что помогает:

- trickplay и изображения глав выключены (см. выше);
- если архив раздаётся с тех же дисков — на время первого сканирования поставить раздачу на паузу;
- **не открывать список всех сериалов**, пока идёт сканирование: Jellyfin 12 считает для него
  статистику просмотров по всей медиатеке, это минутами держит базу и тормозит сканирование;
- повторные сканирования обрабатывают только новое и занимают минуты.

## Как это работает

Сопоставление папки/файла с релизом, по порядку:

1. ID AniLiberty, если уже есть (после «Идентифицировать» или прошлого обновления).
2. Имя торрента: имя папки/файла (для дерева симлинков — имя, на которое указывает ссылка) сравнивается
   с `dn` из magnet-ссылок `/api/v1/anime/torrents`.
3. Очищенное название (без `- AniLibria.TV [WEBRip 1080p]`, подчёркиваний и скобок) против
   названий из того же индекса.
4. Поиск AniLiberty, затем Shikimori: сначала точное совпадение слов названия, затем «все слова запроса
   есть в названии» с минимумом лишних слов; номера сезонов нормализуются (`S2`, `TV2`, `2nd Season` → 2).

Номер серии берётся из тега `[07]` в имени файла AniLiberty — штатный парсер Jellyfin путается
на названиях с цифрами (`100-man no Inochi…` → серия 100).

## Сборка из исходников

```bash
dotnet build src/Jellyfin.Plugin.AniLiberty -c Release
# → src/Jellyfin.Plugin.AniLiberty/bin/Release/net10.0/Jellyfin.Plugin.AniLiberty.dll
```

Нужен .NET SDK 10. Релиз: `git tag -a v0.3.1.0 -m "что нового" && git push origin v0.3.1.0` —
GitHub Actions соберёт zip, создаст релиз и добавит версию в `manifest.json`.

## Что где

```
src/Jellyfin.Plugin.AniLiberty/
  Plugin.cs, ServiceRegistrator.cs   точка входа плагина и регистрация сервисов
  Configuration/                     настройки и страница настроек в панели
  Api/
    AniLibertyClient.cs              публичное API: релизы, поиск, индекс имён торрентов, франшизы
    AccountClient.cs                 API аккаунта: вход по коду, таймкоды, избранное, коллекции
    ShikimoriClient.cs               запасной источник метаданных (с ограничением частоты)
    ReleaseResolver.cs               сопоставление папки/файла с релизом
    NameNormalizer.cs                разбор имён AniLiberty, номера серий
    Http.cs, Models.cs               HTTP с таймаутами/повторами, модели ответов
  Providers/                         провайдеры метаданных и изображений Jellyfin, сегменты опенингов
                                     (SegmentProvider), правило скрытия корневых файлов, номера серий
  Sync/
    AccountStore.cs                  привязки аккаунтов (accounts.json)
    SyncService.cs                   трёхстороннее слияние прогресса, избранного, коллекций
    PlaybackSyncService.cs           отправка прогресса во время просмотра
    AccountSyncTask.cs               плановая синхронизация аккаунтов
    LibraryIndex.cs                  локальные элементы по ID AniLiberty
    FranchiseTask.cs                 коллекции-франшизы (плановая задача и после сканирования)
  Web/
    AccountController.cs, link.html  страница и API привязки аккаунта
    MenuLinkStartupFilter.cs         пункт «AniLiberty» в меню веб-клиента
scripts/
  aniliberty-tree.py                 дерево симлинков для медиатек
  aniliberty-tree.conf               пример конфига (/etc/aniliberty-tree.conf)
  aniliberty-tree.service, .timer    пересборка раз в час
  install.sh                         установка всего этого одной командой
manifest.json                        репозиторий плагинов для Jellyfin
.github/                             сборка релизов
```
